# Demichev Voice

Самостоятельное нативное приложение для диктовки на Mac с Apple Silicon,
macOS 14 или новее. Работает локально через Parakeet v3 и Whisper Turbo.
Без аккаунта, подписок, телеметрии и облачного распознавания.

## Использование

1. Перетащите Demichev Voice.app из DMG в Applications.
2. Выберите и скачайте модель (около 630 МБ). Файлы проверяются по закреплённым
   хешам; интернет нужен для первоначальной загрузки.
3. Разрешите микрофон, а для автовставки — «Универсальный доступ».
4. Удерживайте Control + Option + Пробел в текстовом поле и диктуйте.
   Отпустите клавиши для распознавания. Esc отменяет операцию.

Можно выбрать запись по повторному нажатию, микрофон и язык, настроить
сочетание клавиш и добавить замены в личный словарь. Результат копируется
в буфер обмена; автовставка работает только в исходное неизменённое поле.
Enter не отправляется. Для несовместимых редакторов используйте Cmd+V.

Модели хранятся в `~/Library/Application Support/ru.demichev.voice/Models`.
Настройки и словарь принадлежат только этому приложению. Постоянной истории
нет; временный звук удаляется после распознавания или отмены. После аварии
временный файл может остаться. Расшифровка остаётся в системном clipboard.

## Сборка и проверка

Нужны Apple Silicon, Xcode со Swift 6 и XcodeGen:

```sh
xcodegen generate
xcodebuild -project DemichevVoice.xcodeproj -scheme DemichevVoice \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath build/Debug test
bash scripts/package.sh
```

GitHub Actions проверяет сборку, XCTest, лицензии и секреты. Артефакт
`Demichev-Voice-macOS-arm64` содержит DMG и SHA-256; `diagnostics` — логи и XCTest.
Обычные тесты не скачивают модели. Для отдельной проверки распознавания задайте
`DEMICHEV_INTEGRATION_AUDIO` (путь к синтетическому WAV/AIFF) после загрузки
обеих моделей в приложении. Для проверки без сети выполните
`bash scripts/offline-check.sh /absolute/path/to/synthetic.wav`.

Приложение подписывается ad-hoc и **не нотарифицировано Apple**. Для первого
запуска скачанной сборки может понадобиться штатное разрешение macOS.
CI не создаёт публичных релизов.
