# Demichev Voice

Самостоятельное приложение для локальной диктовки на macOS 14+ / Apple Silicon.
Swift 6, SwiftUI, Core Audio, WhisperKit, FluidAudio, KeyboardShortcuts.

Не добавлять аккаунты, платные API, серверное распознавание и телеметрию.
Не включать модели, звук, расшифровки, ключи и сборки в Git.
Тесты по умолчанию не скачивают модели и не запрашивают разрешения.
Проверять автовставку только в пустом документе; Enter не нажимать.

Настройки проекта находятся в project.yml; XcodeGen генерирует Xcode-проект.
Подпись по умолчанию ad-hoc. Лицензии используемых библиотек сохранять.
Изменения коммитить небольшими логическими частями.
