# Аудит Demichev Voice 1.0.2

Дата: 2 октября 2026 года. Область проверки — самостоятельное приложение,
настройки, локальное распознавание, ресурсы, зависимости, XCTest, GitHub Actions
и DMG. Сервер, DNS и настройки операционной системы пользователя не изменялись.

## Исправленные дефекты

| Область | Проблема | Исправление и проверка |
| --- | --- | --- |
| Модели | Маркер установки оставался после обнаружения повреждённого файла | Перед проверкой маркер снимается; новый содержит отпечаток закреплённого каталога. XCTest проверяет неудачную проверку и ремонт файла. |
| Хранилище | Проверка строкового пути не исключала символические ссылки внутри каталога | Чтение, установка и удаление отклоняют ссылки. Тест сохраняет файл за пределами хранилища. |
| Загрузка | Замена повреждённого файла начиналась с удаления старого | Проверенный файл сначала помещается на том же томе, затем заменяется атомарно. Проверяется запас места для временной копии. |
| Загрузка | Продолжение и ошибка передачи проверялись недостаточно | Искусственная передача проверяет хеш, сохранение старого файла при ошибке и повторную подготовку без сети. Обычные тесты не скачивают модели. |
| Настройки | Отсутствующий или неизвестный ключ сбрасывал все настройки | Поля восстанавливаются независимо; корректные модель, вход и словарь сохраняются. Число и длина правил ограничены. |
| Память | Неудачная загрузка и выбор ещё не скачанной модели оставляли предыдущую модель в памяти | Движок освобождается перед подготовкой и после ошибки. Повторная загрузка не использует прежний экземпляр без проверки. |
| Конкурентность | Во время асинхронного освобождения движок мог принять другое действие | Освобождение сериализуется с загрузкой и распознаванием. |
| Отмена | Зависимость могла вернуть результат после отмены | Контроллер проверяет отмену до публикации, остаётся занятым до завершения и удаляет временный звук. Проверено зависимостью, намеренно возвращающей поздний текст. |
| Запись | Отпускание горячей клавиши завершало запись, начатую кнопкой | Источник начала записи учитывается отдельно. Проверены оба сценария и повтор после ошибки входа. |
| Микрофон | Остановка аудиодвижка при смене устройства оставляла интерфейс в записи | Остановка обнаруживается, запись отменяется с объяснением. Исправлены владение строками Core Audio и уровень многоканального входа. |
| Аудиофайлы | Ограничение длительности проверялось после полной конвертации | Формат, длительность, частота и число каналов проверяются до ресемплинга. |
| Приватность | Файлы после аварии могли оставаться бессрочно | Собственные записи старше суток очищаются при следующем запуске; свежие, посторонние и ссылки не удаляются. Каталог и файлы доступны только текущему пользователю. |
| Результат | Неудачная новая запись скрывала предыдущий результат | Последний результат сохраняется. Ошибка записи в clipboard больше не объявляется успешным копированием. |
| Разрешения | Нерабочая интеграция Accessibility оставалась в сборке | Удалена целиком. Ввод — через Cmd+V. Различаются состояния разрешения микрофона, повторный запрос блокируется. |
| Диагностика | Неполная CLI-команда могла открыть приложение и зависнуть | Отсутствующий путь и конфликтующие команды завершаются с кодом 2. После отмены проверяются повторное распознавание и загрузка. |
| Упаковка | Повторная сборка той же версии DMG завершалась ошибкой | Разрешена замена собственного артефакта сборки; подпись, лицензии, образ и SHA-256 проверяются. |
| CI | Устаревшая среда checkout и параллельные устаревшие сборки | Checkout закреплён на v6; новые push отменяют предыдущую сборку той же ветки. |
| Интерфейс | Не было проверки отрисовки всех вкладок | XCTest создаёт три вкладки с искусственными данными без микрофона и горячих клавиш; PNG входят в diagnostics для визуальной проверки. |

## Проверки

- Сборка Debug и Release на macOS 26 / ARM64, Swift 6; генерация XcodeGen
  должна совпадать с закоммиченным проектом.
- XCTest: целостность файлов и путей, восстановление настроек, правила словаря,
  переходы записи и отмены, очистка, CLI и отрисовка интерфейса.
- Gitleaks: вся история и текущие файлы; точечное исключение публичных хешей.
- Отдельный workflow скачивает обе закреплённые модели и проверяет речь,
  тишину, отмену, освобождение и повторное распознавание с запрещённой сетью.
- Установщик: arm64, Bundle ID, подпись ad-hoc, совпадение лицензий,
  `hdiutil verify` и проверка SHA-256 скачанного артефакта.
- Зависимости закреплены в Package.resolved. На дату аудита в публичной базе
  GitHub Reviewed Advisories для Swift не найдено записей для четырёх
  используемых пакетов. Это не доказывает отсутствие неизвестных уязвимостей.

Результаты конкретной ревизии доступны в
[Actions](https://github.com/mcdimas/DemichevVoiceApp/actions). При неудачной
проверке сборка не считается проверенной; CI не публикует релизы.

## Практические ограничения

- Сборка ad-hoc **не нотарифицирована Apple**. Gatekeeper может потребовать
  «Всё равно открыть», пароль или Touch ID. Изменение приложения не отменяет
  системное подтверждение. Для распространения с обычной проверкой Apple нужны
  Developer ID и нотарификация через Apple Developer Program.
- Автовставка отключена. Разрешение микрофона необходимо для записи.
- Проверки CI не заменяют проверку реального микрофона, Bluetooth/USB,
  горячих клавиш, сна Mac и установки скачанного DMG на конкретном M1.
- Изображения вкладок — проверка отрисовки, а не полный интерактивный UI-тест.
- Здесь нет проверки всего содержимого пользовательского Mac или гарантии
  отсутствия всех возможных ошибок. Проверялись доступный код и воспроизводимые
  сценарии приложения; аппаратные ограничения указаны явно.
