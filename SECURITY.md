# Приватность и сообщения об ошибках

Речь обрабатывается на устройстве. Сеть используется для загрузки публичных
моделей по закреплённым URL; запросы не содержат аудио или расшифровок.
Файлы моделей проверяются по размеру и хешу. Приложение не имеет аккаунтов,
платных API, серверного распознавания, аналитики или постоянной истории текста.

Микрофон включается пользователем. Результат остаётся в системном буфере
обмена; другие приложения могут читать его согласно настройкам macOS.
Автовставка требует разрешения Accessibility и выполняется только при
неизменном исходном поле, содержимом и выделении. Защищённые поля исключены.

Не прикладывайте к issue личные записи, расшифровки, токены, сертификаты
или системные дампы. Используйте искусственный пример и версию приложения.
Сборка ad-hoc не является нотарифицированным релизом.
